IdeaListed Extension Icons

Right-click on each icon and "Save image as..." to download.

Setup Instructions:

  1. Right-click each icon above and save to the icons/ folder
  2. Save as: icon16.png, icon48.png, icon128.png
  3. Load the extension in Chrome/Vivaldi:
    • Go to chrome://extensions
    • Enable "Developer mode"
    • Click "Load unpacked"
    • Select the chrome-extension folder
